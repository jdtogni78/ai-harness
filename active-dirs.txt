# Allowlist for the ai-harness supervisor.
#
# One basename per line. Lines starting with `#` and blank lines are ignored.
# The supervisor re-reads this file every TICK_SECS (~30s):
#   - basenames added here spawn a server within one tick,
#   - basenames removed (or commented out) get SIGTERM'd within one tick.
#
# `dev` is the special name for the ~/dev root itself (mm-dev).
# Every other entry is a basename under ~/dev (e.g. `your-app` -> mm-your-app).
#
# HOST SCOPING (this file is shared across machines via git): append `@<nick>`
# to spawn an entry only on the host whose nickname is <nick>. A bare basename
# (no `@`) spawns on every host. Several hosts: `name@nick1,nick2`. Each host's
# nickname is REMOTE_CONTROL_HOST (set in its plist) or, if unset, derived from
# its hostname (the first hostname label lowercased). Example:
#   your-app@host1            -> only the host nicknamed "host1"
#   dev@host1,host2           -> both the host1 and host2 hosts
#   another-app               -> every host that has ~/dev/another-app
#
# Manage with: /remote-control-dirs
